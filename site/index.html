The idea

Agents work for an hour, then wait in silence.

You start one on the server, two on your laptop, and go back to your own work. Somewhere a permission prompt has been waiting for twenty minutes. Nothing tells you, until you happen to look at the right window.

tallylight is the missing signal. It sits quietly next to your agents and lets any screen know, the moment one of them needs you.

Every agent

Every session on every machine, each in its place, with what it's doing and which model is answering.

Any screen

A phone, a tablet by the desk, a terminal, an e‑ink launcher. Your app can show it too.

Only yours

End to end encrypted. Your code and what your commands print never leave the machine.

Why it's different

Others built an app. We built the missing piece.

Plenty of tools show agent status. Each one asks for something in return: an account, a subscription, a single vendor, a single network. tallylight asks for none of it.

Free and open source
MIT or Apache-2.0. No paid tier, no subscription, nothing held back.
No account
Your machines pair directly with your screens. No sign-up, and no company server that sees your sessions.
Works away from home
Not limited to your local network. It connects straight through home and office routers, with an encrypted relay as a fallback.
Nothing to change in how you work
It follows agents where they already run. No wrapper, no special terminal, no need to start them through it.
Not tied to one vendor or one screen
States follow the open A2A standard, and any app can embed the library to show them its own way.
On a television set, a small red lamp sits on top of each camera. When it lights, everyone knows which one is live.

The name

It's called a tally light. The presenter doesn't check the monitors; they look for the red lamp.

We wanted the same for agents: a calm screen where nothing moves until something needs you, and then one light comes on.

How it works

Three steps, then forget about it.

  1. one

    Install

    A single small program per machine. It listens to the signals your agent already sends; it never launches or wraps it. tallylight install

  2. two

    Pair

    Scan a QR code from your screen. The code works once and expires after five minutes. tallylight pair

  3. three

    Glance

    Each agent shows as working, waiting for you, done or stopped on an error. Every state has its own shape, so it reads even in black and white.

What's next

Today Claude Code. Tomorrow the rest.

tallylight follows Claude Code on macOS and Linux today. What follows is the plan, in order.

Now

  • Claude CodeEvery session, its model, what it's doing.
  • Terminal and AndroidA terminal view, and a library any Android app can embed.

Next

  • More agentsCodex, Copilot CLI, Cursor and OpenCode. Close by design, not tested yet.
  • iPhone and MacThe same library, for Apple screens.
  • Your own relayOne command to run the fallback relay on your own server.

Later

  • A desk objectA small Bluetooth display that lights up when an agent waits.
  • Wake a sleeping phoneOptional notifications, run by each app with its own keys.
  • Answer from the screenApprove a request without walking back to the keyboard.

For developers

A building block, not another app.

The daemon, the state format and the client library are the product. States follow the A2A standard, and the library is plain Rust with Kotlin bindings, Swift next.
