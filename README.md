# tallylight

The link between any coding agent and any screen.

One binary per machine reads the state of your agent sessions (working, waiting for you, done),
translates it into a standard vocabulary (A2A `TaskState`) and streams it to your paired devices,
end-to-end encrypted, with no account and no server.

Status: early design. See `docs/ARCHITECTURE.md` and `docs/DECISIONS.md` (in French).
